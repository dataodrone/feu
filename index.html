Mode d’emploi — analyse 3D du Trail de Sadirac

1. Choisir un parcours

Dans le panneau de gauche, cochez ou masquez les traces 8 km, 12 km et 21 km. Le menu Profil analysé définit le parcours utilisé par le profil et le traceur.

2. Faire avancer le traceur

Utilisez le bouton ▶ pour lancer l’animation. Vous pouvez aussi déplacer le curseur horizontal situé au-dessus de la carte.

3. Utiliser le GPS sur site

Utilisez le bouton 📍 Localiser placé dans les outils de carte. La carte affiche votre position, l’écart à la trace, le kilomètre le plus proche et une liaison vers le point du parcours le plus proche. Sur mobile, publiez de préférence le viewer en HTTPS : un fichier HTML ouvert localement peut bloquer la géolocalisation.

4. Déplacer manuellement depuis le profil

Cliquez dans le profil altimétrique ou dans la bande de pente. Maintenez le clic et faites glisser la souris. Sur téléphone, posez le doigt puis glissez. Le coureur et la caméra suivent immédiatement.

5. Comprendre les repères du profil

  • Repères kilométriques : grille verticale de distance.
  • Mini / maxi : points d’altitude minimale et maximale.
  • Pentes colorées : coloration selon l’intensité de la pente locale.

6. Fonds de carte et relief

Choisissez OSM, OpenTopoMap, IGN Plan ou orthophoto. Activez le relief 3D, les courbes de niveau, le cadastre et les bâtiments OSM 3D selon le besoin.

7. Tracer un segment libre

Cliquez sur Tracer un segment, puis choisissez deux points sur la carte. L’application calcule le profil altimétrique du segment. Utilisez Effacer segment pour revenir au parcours.

8. Lire les statistiques

Les panneaux indiquent la distance, l’altitude courante, les dénivelés cumulés, les pentes maximales, l’angle maximal et la source altimétrique utilisée.

9. Exporter les résultats

Vous pouvez enregistrer la carte, exporter le profil en image PNG, télécharger les données CSV ou générer un GPX enrichi avec les altitudes calculées.

Astuce : pour examiner précisément une montée, désactivez temporairement le suivi caméra, puis faites glisser le curseur directement dans le profil.
